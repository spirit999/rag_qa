## 一、解析结果

- 解析脚本：`query-rewrite/parse_docs.py`，纯 Python 标准库 + libreoffice + pdftotext，无新增依赖。
- 解析文本：`data/parsed/` 下 130 个 txt，每份带 meta 头（大类/源路径/制度名/文号/表格数），正文保留"第X章/第X条/（一）"结构，表格内容按行还原为 `单元格 | 单元格`。

- 129 份成功；1 份损坏：`考核办法/各职能部门专项考核制度清单-发文版.xlsx`（仅 165 字节，内容是一个用户名，非真实文件），同名非发文版完好，不影响语料。
- PDF 已做中文硬换行合并（pdftotext 的物理换行还原成完整条文）。

## 四、这批语料里最有价值的术语对照（示例）

口语 → 公文的"词汇鸿沟"确实非常明显，典型例子：

| 员工可能问的 | 制度原文术语 | 出处 |
|---|---|---|
| 老员工休假怎么算/年假 | 带薪年休假（累计工作年限定 5/10/15 天） | 请（休）假管理办法 |
| 结婚能歇几天 | 婚假（3 天国家规定 + 7 天增加，一年内有效） | 请（休）假管理办法 |
| 生孩子休假/男方陪产 | 产假 / 延长生育假 / 陪产假 / 哺乳假 | 请（休）假管理办法 |
| 生病请假/医疗期 | 病假（按工龄定 3-24 个月医疗期） | 请（休）假管理办法 |
| 工伤休假 | 工伤假 / 停工留薪期（一般不超 12 个月） | 请（休）假管理办法 |
| 白事假 | 丧假（3 天含节假日） | 请（休）假管理办法 |
| 迟到扣钱吗 | 迟到早退扣绩效工资（50/100/200 元） | 请（休）假/考勤办法 |
| 报销机票要什么手续 | 差旅费·城市间交通费 + 《出差申请单》逐级审批 | 差旅费管理办法 |
| 出差餐补/打车 | 伙食补助费 / 市内交通费 | 差旅费管理办法 |
| 出差借钱 | 借款 / 《借款申请单》 | 借款报销管理办法 |
| 请客户吃饭 | 公务接待 / 商务接待 / 业务招待费（三个概念分属不同制度） | 公务/商务接待管理办法 |
| 盖公章 | 用印 / 印章 / 资质证照 | 印章和资质证照管理办法 |
| 申请公车 | 保障用车 | 交通安全和车辆管理办法 |
| 落户/公司户口 | 集体户口 | 集体户口管理办法 |
| 公租房/人才房 | 人才公共租赁住房 | 人才公共租赁住房实施细则 |
| 提建议有奖吗 | 合理化建议 | 合理化建议管理办法 |
| 调岗/离职 | 人员流动（内部调岗、待岗、外部调动、离职） | 人员流动管理办法 |

| 外包/派遣能报销吗 | 劳务派遣、劳务外包人员视同员工 | 差旅费管理办法 |

另外两个结构性发现：

1. **费用科目体系天然成表**：会议费（11 份制度）、差旅费（9 份）、外协费（7 份）、培训费（7 份）、交通费/住宿费/材料费（6 份）、业务招待费、劳务费、评审费、咨询费、市内交通费、伙食补助费……这些是 BM25 同义词扩展和类别路由的现成词表。
2. **外部法规引用密集**：劳动法、公司法、保守国家秘密法、职工带薪年休假条例及其实施办法、保密资格标准、企业会计准则、党章等。用户问"国家规定年假几天"这类问题时，改写应保留"条例/国家规定"信号。

## 五、术语表在 Query Rewrite 中怎么用

1. **注入改写 prompt**：把核心术语表按类别裁剪后作为领域知识给 Qwen3-8B，约束它输出公文措辞（"休假"→"带薪年休假"、"机票报销"→"差旅费·城市间交通费"）。
2. **BM25 侧确定性同义词扩展**：不依赖 LLM，命中口语词时用对照表直接 OR 扩展公文词（如"盖章 OR 用印 OR 印章"），保证关键词路不零召回。
3. **类别路由**：13 个大类 + 归口部门词表支撑 query 理解结果里的 category 字段。
4. **主体识别**：人群身份 16 条用于识别"劳务人员/返聘/女职工/领导人员"等适用对象差异（同一条政策适用范围不同）。
5. **时效信号**：4 组多版本制度配合当前日期做版本过滤。
